## Use
Unzip in a new repository. Node >=20 and Python 3 with Pillow. Run npm run build then npm run dev; set SITE_BASE_PATH for subdirectory hosting. Package includes editable source generators, public assets and content. Complete template-config.json; replace all demo data and media with authorized content, review legal notices, connect approved services, test production independently. Keep noindex until approval. Do not alter the master. Catalog creates a local project plan, not a GitHub repo.
