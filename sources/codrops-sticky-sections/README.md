# Codrops — Animations for Sticky Sections

Fuente original: https://tympanus.net/codrops/?p=75532

ZIP de referencia entregado por el usuario: `ATREZZO_03_StickySections_15_MAC_LISTO(1).zip`.

15 variantes originales identificadas como demo1..demo15. En ATREZZO se registran como `ATZ-STK-001`..`ATZ-STK-015`; las fórmulas GSAP de cada script fueron aisladas en módulos individuales y sus parámetros de movimiento (GSAP start/end, scrub, transforms, ease) conservados.

Código MIT (ver LICENSE). Imágenes originales acreditadas a Annas Muslimin/Vecteezy: licencia comercial **no comprobada**, por eso se han sustituido por composiciones SVG abstractas originales de prueba. El suavizado global Lenis de la demo no se incorpora automáticamente a la web de cliente; se mantiene scroll nativo y GSAP/ScrollTrigger. La sensación del scroll puede diferir levemente de la demo si el sitio destino no incluye su propio smooth scroll.
