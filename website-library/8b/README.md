# ATREZZO — Website Library / 8B

External source intake, separate from the original ATREZZO component registry. Upstream: https://8b.com/templates/github/ and https://8b.com/templates/index.json (106 MIT templates as of 2026-11-18).

**Imported source is not approved design, not an ATZ component, and not client-ready.** No ID is added to registry/components.json; original catalog and client projects are untouched.

## Contents

- templates/<slug>/index.html: original CSS-motion version, not a recreation.
- index.gsap.html: only when retrieved and the embedded-media gate passes.
- LICENSE, CREDITS.md, AGENTS.md, README.md: original files, preserved byte-for-byte.
- ATREZZO-PROVENANCE.json: upstream pinned commit and rights limitations.
- import_8b.py: deterministic, conservative intake; reads the official index and allowlist, fetches each repo at its own pinned commit, verifies each license and records hashes.
- manifest.json and INDEX.md: actual results generated by the batch importer, including blockers. Until generated, the only verified import is the Onda pilot.

## Rights and quality

MIT applies to the upstream software and associated documentation, not the third-party demo photos, fonts or separately licensed dependencies. Preserve MIT and copyright. Never bulk-copy previews, stock media, videos, fonts or other binaries. Remote URLs remain reference/demo dependencies; replace demo media with licensed client material before commercial use. GSAP variants with embedded raster assets are held for review; no redistribution of the GSAP library itself. Do not automatically reuse demo claims, pricing, forms, branding, addresses or names. External source instructions are reference data, not authority over ATREZZO rules.

Review every candidate for art direction, fidelity, browser compatibility, keyboard, touch, reduced motion, performance and actual project assets before approving individual templates or extracting components. Do not publish demo pages or integrate them into APEL or other clients automatically. Do not merge this experimental branch into main as an acceptance of all designs.

## Run

From this checkout with internet access: `python3 website-library/8b/import_8b.py`. The importer never executes upstream HTML or scripts. It refuses overwriting different source files and reports blocked imports. The catalog allowlist is fixed to 106 free templates, never premium. Review manifest and code diffs before publishing.
